# 2026-11-12 广告内容采集改进

版本 1.0.3（4），继承 1.0.2 的导航和返回键修复。

- 激励和副广统一通过 ATAdInfo.getNetworkPlacementId() 获取广告源广告位 ID，扩展字段仅作空值后备。
- 内容字段采用白名单、空值清理和明确优先级，仅复制文本或素材/广告位的数值 ID；不对 SDK 对象直接 toString，不上传未知扩展值。
- 原生素材不再仅在渲染前快照：加载时、渲染后、真实展示/点击/关闭回调重新读取。保留同一素材之前已取得的非空字段；每次事件生成独立快照，SDK 后续变动不改写已排队事件。
- 同时读取聚合 SDK 原生素材公开 getter、白名单素材 networkInfoMap，及通过 getObject() 返回的 KsNativeAd 公开产品名、应用名和包名接口。模板返回其他对象时不会反射私有数据，也不把描述、平台名或应用发布者当成广告名称/广告主。
- 不新造展示事件，不修改发奖条件，不变更线上后台或广告位投放配置。

模板广告、激励或其他全屏广告并不保证提供名称、包名、素材 ID。缺失保持真实空值；若投放端选择的模板不公开素材，仍需广告平台开放能力或调整为可取得素材的自渲染广告位。本版不宣称消除所有来源的字段缺失。

构建：JDK 17 / Android SDK 35；执行 Debug、Release 单元测试及 Lint、assembleRelease。真机结果及交付文件见工作区 docs/ya-zhi-yi-ji-ad-content-fix-20261112.md。
