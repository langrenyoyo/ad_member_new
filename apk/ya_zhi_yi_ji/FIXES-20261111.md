# 2026-11-11 源码修复说明

基于用户提供的 ya_zhi_yi_ji.zip 独立修复，保留原生 Compose 页面及包名，版本 1.0.1、versionCode 2。

## 修复内容

- 激励广告展示元数据同步持久化，再异步上传；complete 及补发前优先上传同一广告会话的 shown。clicked、closed 等其他事件的网络失败不阻塞结算。
- ECPM_DISPLAY_BINDING_REQUIRED 保留奖励任务并返回待确认状态，自动退避重试；真正无效的证明和不存在的会话仍按原有失败条件处理，不放宽后台校验。
- 副广与展示元数据任务退出登录后保留，按原会员隔离；只在该会员重新认证后、上报窗口内重试。兼容旧版副广队列格式，过期和损坏事件可清理。
- 在请求广告时捕获所属会话，旧 SDK 回调不能在账号切换后归属新会员。
- 修复重试任务运行期间或冷却期间到达的新触发被丢弃；会员筛选在批次截取前完成，补发连续处理后续批次。
- 横幅和原生视图移除不再伪装成用户关闭；使用 SDK 真实关闭/不喜欢回调。
- 原生广告区分模板与自渲染，绑定标题、描述、媒体/图片、CTA、广告标识及下载应用信息，并调用 SDK prepare。页面销毁或加载取消时释放资源。
- 使用原生素材公开接口补充广告名称、应用名/包名和广告主；补齐激励上报的包名、广告主和平台广告位。SDK 不提供的字段保留真实缺失状态。
- 补齐会员中心广告记录的内容及类型展示。源码中的独立广告历史本来已经有新字段，不将其算作本次新增。
- 递增版本号，新增 BuildConfig.SOURCE_FINGERPRINT 标识实际主源码与应用构建脚本快照，避免只依赖上级目录 Git 信息。
