`PARITY_MEMBER_TAB=basic` 运行 `scripts/compare_member_lottery.py`，将两端表单预填为同一套虚构身份信息。空头像场景清空对标现有附件预览列表；只改变浏览器中的模拟状态，不提交业务修改。预填不触发输入校验，以免把“刚编辑过”的校验样式和初始状态混为一谈。

修正了本地头像地址框的高度、边框、背景和字体，避免头像行多出 7px 导致后续字段下移。密码和支付密码补齐“不修改密码请留空”提示。基础页单选按钮行按对标 29px 高度、间距和颜色调整。

已补齐对标头像行的“上传”和“选择”入口。参考的附件选择接口明确返回无权限，本地点击“选择”按同一权限结果提示，不生成或伪造附件记录。会员编辑表单不再显示参考中不存在的支付宝姓名编辑行；列表中的支付宝姓名列仍保留。完整滚动状态、头像非空状态和输入校验仍待验收。
