# 微信登录设置系统密码 1.0.19

首次微信注册后，应用显示独立系统密码设置页。用户确认密码并完成本账号微信验证，服务端保存密码及显式设置标记，随后进入首页。已设置账号不重复设密。设置页提供退出登录，错误以弹窗显示。

支付宝绑定页移除新密码、确认密码及微信/短信设密入口，只填写收款账号、姓名和已有系统密码，保留原收款绑定密码校验。提现规则不变。

迁移 e941_system_password 为会员新增 system_password_set 字段；新微信账号设为 false。历史自动创建的微信账号缺少可靠标记，会要求重新确认设置一次，不修改原密码散列。微信验证、短信验证及当前密码验证成功设置密码后均标记为已设置。

版本 1.0.19（20）。验证包含 Android 单元测试、Lint、正式构建，以及微信设密、会员策略和提现测试。新增检查覆盖新微信账号、本人/他人授权、标记持久化和旧数据迁移。真机端完整微信交互仍待验证。
