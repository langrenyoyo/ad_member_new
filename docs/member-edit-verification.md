# 会员编辑字段核查

抽奖字段分组复核：按对标 `member-edit-fields.json` 修正“抽契”错字、两组次数标签，并将每组开始/结束倒计时归入同一行。浏览器测试比较五组标签及组内字段名，与对标元数据一致；跨抽奖、下载、代理页签修改后，一次 PATCH 完整包含各页修改值，`raffle_open` 为数字。字段与生命周期回归通过，本地截图见 `visual-baseline/verified/member-edit/lottery.png`。分组和标签已有证据，倒计时输入框的精确间距、分隔符以及整页像素效果尚未双端验证。

页签显示修正：此前测试仅检查 `hidden` 属性，未发现 `.detail-field { display:grid }` 覆盖浏览器隐藏规则。现已补充隐藏样式，并逐一验证四个页签只有本页字段实际参与布局；切换后抽奖次数草稿保留。抽奖和下载已有字段，已删除过时的“尚未接入”占位提示。字段、生命周期、工具栏三项浏览器回归和 JS 语法检查通过。此项纠正了此前“其余字段已隐藏”的过强结论，尚不证明整窗像素一致。

会员编辑已覆盖资料、状态、代理比例、两套抽奖配置及下载地址。单选项使用对标值，性别和 VIP 使用下拉框。保存只发送实际变更，单选值按 JSON 数字提交，未知枚举值不会被默认覆盖。

窗口为 800×600，标题栏 45 像素，固定底栏 53 像素，单列字段布局；确定/重置按钮和四个页签已接入。头像支持图片类型检查、浏览器预览和地址输入同步。

后端已新增并持久化实名状态、两套抽奖配置、下载地址和密码哈希字段；迁移 head 为 `e917_member_password_hashes`，开发环境会补齐缺列。旧数据迁移验证通过，历史实名状态保留为未知。

`verify_member_edit_fields.py`、`verify_member_edit_lifecycle.py`、`verify_member_toolbar.py`、`verify_member_payment_migration.py` 及后端全套 46 项测试通过。

仍未完成对象存储上传、密码/支付密码安全业务、完整高级页签语义和真实支付链路。data URL 仅用于浏览器预览，不能作为生产上传方案；当前证据不支持全站一比一或直接上线结论。

密码字段已改为安全存储接口：会员创建/更新接受 `password` 与 `pay_password`，服务端使用现有 PBKDF2 哈希和独立盐保存，仅返回会员公开字段，不序列化明文。编辑页使用空的密码输入框，未填写不会覆盖原密码。当前尚未接入会员端登录或支付密码校验流程，也未把此项计为完整业务验收；上线前仍需针对会员认证、找回、限流和支付校验建立独立接口与测试。

`verify_member_password_contract.py` 已确认独立盐哈希、错误密码拒绝和公开字段排除；迁移脚本已确认旧库可升级到 `e917_member_password_hashes` head。
头像选择限制为 2MB；超限或非图片文件会保留原地址并在表单内提示，回归测试已覆盖。
