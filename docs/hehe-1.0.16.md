# 禾合 1.0.16

## 开屏关闭

修复开屏使用 APP 根容器展示却不移除广告视图的问题。现在使用独立全屏容器；关闭、加载失败、展示异常、15 秒兜底超时及 Activity 销毁均移除自身容器，清理 SDK。重复加载/超时回调不会重复展示，已销毁实例的加载回调被忽略。此为代码发现并修复的风险点，尚无反馈手机的现场日志，不能认定是所有卡顿的唯一原因。

## 启动准备页面

启动更新检查期间展示准备页面。已登录用户在授权完成、SDK 和应用配置就绪后并行预加载开屏、激励、插屏、Banner、信息流，每完成一项增加进度。未配置、失败及超时也结束该项；SDK/配置等待最多 8 秒，广告加载最多约 10 秒，检查结束进入正常页面。未登录时先显示登录页，登录后再执行会员归属的预加载。

开屏、插屏、Banner、信息流加载缓存按 Activity、广告位及 120 秒有效期管理；取走后交给原有展示逻辑，未取走的缓存到期销毁。预加载不展示隐藏广告。激励采用隔离的 SDK 实例预加载和检查报价，结束后销毁，正式领取仍由新奖励会话加载，以保留 user_id、extra_data 的绑定与发奖安全。预加载报价不保证等于之后实际展示报价。

## 后台记录

APP 上报 `/api/app/v1/ads/preload-events`，使用现有持久事件队列重试并绑定原用户。服务端校验会员应用、广告位、时间与幂等标识；加密 ECPM 由服务端解密。记录单独存为 `ad_preload`，不创建实际广告展示、奖励会话、金币或分佣。

后台：APP 业务规则 → 加载游戏 ID 1 → 启动广告预加载记录。支持会员 ID 筛选和翻页。字段含会员、类型、广告位、加载结果、耗时、人民币 ECPM、报价状态、时间。SDK 未提供报价时显示“—/未提供”；预加载报价只供诊断，不能作为广告已获收入。

## 微信昵称

微信授权 code 兑换成功后，服务端使用 access_token 请求微信 userinfo，核对 openid，更新会员昵称和微信身份昵称；仅返回给业务代码昵称/头像，不保存 access_token。昵称接口失败不影响登录。中文、字母、数字、标点保留，表情、控制符等不可兼容字符替换为 ?，最长 128 字符。会员列表默认显示“微信昵称 / 昵称”。

历史会员未保存的微信昵称无法离线还原，下次微信登录时更新；原有微信身份已有昵称时可同步到空昵称会员。

## 验证与限制

后端覆盖预加载幂等、跨游戏查询隔离、无奖励副作用、鉴权、昵称过滤和微信登录回归。Android 执行单元测试、Lint、Release 构建及签名校验。当前未连接真机，需安装后验收开屏关闭可操作、五类实际填充/报价、弱网超时、返回前台及微信昵称更新；测试不伪造真实广告或收益。
