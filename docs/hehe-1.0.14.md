# 禾合 1.0.14

提现收款账号错误经已验签的支付宝响应识别后，查询原订单；只有确认订单不存在或失败时才退款。查询成功则按到账处理，结果不确定继续冻结和查询。失败退款与提现状态更新同事务，重复回调不重复退款。失败及驳回订单不再占用每日提现次数。

APP 提现记录显示失败原因、退款说明及修改支付宝按钮。修改账号继续验证系统密码，处理中订单仍不能换绑；重新提现创建新订单，原订单收款快照保留。

补贴驳回同事务释放活动名额；当天符合实际到账门槛的用户可修改资料后重提。保留历史申请及幂等请求编号，新增有效名额唯一索引。迁移将既有驳回记录标记为不占用名额，不退补贴金币，也不把失败提现计入到账门槛。

验证：支付和补贴相关 41 项测试、30 个子测试及迁移测试通过。手机未连接，客户端交互仍需真机验收。
