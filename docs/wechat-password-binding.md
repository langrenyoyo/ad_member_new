# 微信密码设置与支付宝绑定

新增接口：`POST /api/app/v1/auth/wechat-password`，需要当前会员 Bearer Token。

请求包含 `code`（新取得的微信 App 授权码）和 `new_password`（8–128 位，包含字母、数字）。后端使用会员所属游戏的微信配置交换授权码，仅当返回的 openid 与该会员绑定的 App 身份、AppID 均匹配时设置密码。成功返回 204；不匹配返回 403，弱密码返回 422。不会因客户端声明微信用户或知道会员 ID 而跳过身份校验。

APP 路径：钱包 → 微信验证并设置密码 → 重新授权绑定的微信 → 使用新密码绑定支付宝 → 选择提现金额。支持已创建且初始密码未知的微信账号，也支持通过本人微信重设密码。密码仅保存在当前授权流程内存中，未写入本地配置。

钱包读取 `payment_available`，并检查支付宝绑定状态。未具备条件时禁用提现入口；新增刷新钱包按钮，绑定密码输入采用隐藏显示。

部署要求：先部署包含新接口的后端，再安装新版 APP。无需数据库结构变更。微信 AppID、应用签名及后端 Secret 必须与实际开放平台应用一致。此次未部署线上后端，未验证真实微信授权和真实打款。

验证：新增后端 4 项测试验证身份归属、跨 App 拒绝、认证及密码强度，以及设置密码后使用新密码绑定支付宝；原有 13 项支付宝提现测试通过。微信换码使用模拟响应。

Android Debug 构建成功，23 项 JVM 测试通过，Lint 无错误。真实微信回调、账号切换和提现仍需真机联调。
