# 新增会员核查

只读参考证据 `visual-baseline/reference-verified/member-create-fields.json` 表明当前对标账号的会员工具栏没有新增按钮，访问 `/gameuser/add` 返回“你没有权限访问”。因此无法证明本地简化新增表单与对标的字段、布局或校验一致。新增界面的还原需要可访问的参考证据；本次没有新增对标业务记录。

本地新增生命周期测试复现了连续提交发出两次 POST 的问题。已添加请求期间控件禁用和重复提交抑制，失败保留草稿，结束后恢复控件；响应只作用于原表单和原页面范围，关闭重开后旧响应不能关闭新表单。

`verify_member_create_lifecycle.py` 使用浏览器模拟响应验证重复提交、409 失败保留、重试成功及迟到创建响应隔离。`verify_member_edit_lifecycle.py` 回归通过。这些是本地正确性修复，不是新增功能一比一验收，也不代替服务端幂等机制。

新增后端隔离测试 `test_member_create_scope_failure_is_atomic`：无效主体、无效游戏及主体与游戏不匹配分别返回 404/422，均不创建会员；范围合法时两组密码正确持久化。创建路径的密码哈希已移到范围校验之后，失败请求不先执行哈希。

会员模型当前未声明账号唯一约束；这与管理账号的唯一约束不同。对标新增入口不可访问，尚不能确认会员账号是全局唯一、游戏内唯一或允许重复，因此本轮未添加未经核实的唯一性规则。前端 409 模拟仅验证冲突错误的处理，不证明后端已实现重复账号检测。
