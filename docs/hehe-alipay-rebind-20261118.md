# 禾合支付宝换绑修复

线上出现已拒绝提现仍无法换绑的情况：同一会员另有审核通过但尚未提交支付宝的提现，旧规则将其视作处理中而拦截。

修复规则：

- 验证系统密码后，变更支付宝账号或姓名时，在同一事务中撤回尚未提交打款的提现，返还冻结金币并释放提现次数，然后保存新资料。
- 已排队或渠道处理中的提现继续拦截换绑，避免到账结果不明时退回资金。
- 相同账号和姓名重复保存不撤回提现；重复提交不会重复退款。
- 原提现保留原收款资料与撤回说明，新申请使用新收款资料。
- 密码错误、异常支付记录或冻结余额异常时整体回滚。

接口 PUT /api/app/v1/me/alipay 的响应增加 cancelled_withdrawal_ids，兼容现有 APK。用户保存后重新进入提现页面即可刷新余额和记录。补贴达标仍按实际到账计算。

验证：支付回归测试覆盖多笔撤回、审核通过未打款、重复保存、提现次数恢复、撤回后不再打款、密码错误、处理中拦截、异常订单整体回滚。

本次为后端修复，不更改 APK 版本，不主动执行真实转账或修改用户收款资料。
