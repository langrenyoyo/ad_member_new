# 会员“其它信息”字段补齐

只读采集 `visual-baseline/reference-verified/member-otherlevel-control.json` 确认：对标基础信息页签有 `row[otherlevel]`，标签“其它信息:”，为可编辑单行文本框，界面未设置最大长度。此前本地缺少该字段。

现已在基础页签 VIP 后加入同名字段，支持预填、重置、跨页签保留草稿以及仅提交变化值。接口创建、更新、详情和列表均传递 `otherlevel`；数据库使用非空 TEXT。PATCH 拒绝 null，清空内容使用空字符串。迁移 `e919_member_otherlevel` 为历史记录补空字符串，不从其他字段推导内容。

验证包括隔离数据库中文和特殊字符读写、超过 255 字符、权限限制、无效请求原子拒绝、清空；浏览器验证控件类型与标签、重置、切换页签保留及提交内容；临时旧库验证升级默认值与重复升级保留已有值。

本次未向对标提交业务修改，因此不证明对标服务端的最大长度或内部业务用途。基础页签的完整视觉布局、头像附件选择及其余交互仍待验收。
