# 会员分页对齐

2026-09-17 从已登录对标会员页读取 Bootstrap Table `getOptions()`：`pageSize=10`，`pageList=[10,15,20,25,50,"All"]`，`paginationLoop=true`，`smartDisplay=true`。三条模拟记录时显示记录范围，隐藏页码和每页条数选择。

本地会员页改为以上默认大小和选项，显示记录范围/总数、页码、跳转输入；首尾页可循环。小于一页时隐藏导航，空结果隐藏分页。更改每页大小回到第一页，结果缩减时修正过界页码。其他通用列表仍用原每页 20 条。

“全部”保留会员接口每批最大 200 条的限制，按相同筛选、排序、主体范围继续请求并合并；页面切换或新请求代次发生后停止后续加载，旧结果不能覆盖新页面。该机制不是数据库快照：并发增删期间仍需后续验证一致性。

验证通过：

- `verify_member_pagination_boundary.py`：205 条数据；10/15/20/25/50/全部；首尾循环、有效/越界跳转、主体和筛选保持；40 条的完整末页；总数缩减至 3 和 0。
- `verify_member_sorting.py`、`verify_member_columns.py`：按默认 10 条调整预期，继续验证排序重置、列设置保留和选中行为。
- `verify_member_request_recovery.py`：失败重试、无效筛选、旧响应不覆盖新响应。
- `verify_agent_navigation_scope.py`：主体入口、重置、分页、刷新、标签页及切换范围。
- `node --check public/app.js`。
- `compare_members_fixture.py`：默认三行截图重新生成；差异像素占比从 11.1499% 降至 6.6380%，平均 RGB 差异 4.71136。该指标不证明全站还原率或后端业务一致性。

分页选择器当前使用原生 select，尚未达到对标 Bootstrap dropup 的完全视觉一致。多页页码分布、全部模式在数据并发变更下的行为也未完成双端逐项验证。操作、权限、卡片、导出等范围仍待完成，项目尚不具备全站一比一或上线完成的证据。
