# 项目风险修复记录（2026-10-11）

## 已修复

- 生产启动仅初始化配置指定的管理员，不创建演示业务数据、不调用 create_all 替代迁移。移除附加弱密码超级管理员创建；历史固定账号仅在密码仍为原始弱密码时自动停用，既有请求鉴权会检查账号状态。未连接生产数据库，需部署后确认停用结果及历史日志。
- 通用会员资料接口禁止变更余额、冻结资金、累计收益、上级及所属应用/主体，允许原值随表单提交。避免绕过专用业务路径及跨应用关系变更。
- 新调账接口使用会员行锁、预期余额比对、六位小数校验、金币流水和管理员审计。冻结资金只允许保持原值，必须经提现业务流转；清空金币也拒绝冻结资金未释放的账户并增加锁和审计。
- 新改绑接口使用游戏锁，同时更新 Member 和 Enrollment，检查并发改绑、同应用、状态、邀请等级及循环关系；已签发广告快照不随改绑改变。
- 删除会员检查新增邀请、使用统计、广告会话和分佣流水，关联账户应停用而非硬删除。
- 后台调账、改绑按钮已接入专用接口；调账窗口冻结金币只读并要求原因。
- Compose 透传短信四项配置、挂载持久化上传卷和只读支付宝密钥目录。宿主机设置 ALIPAY_KEY_DIR，容器内密钥路径填 /run/payment-keys/文件名。旧容器图片需先备份再复制到新卷，创建卷本身不会搬迁旧图片。
- PostgreSQL 短信全局手机号/IP 配额使用事务咨询锁，防止不同游戏绕过同一配额；SQLite 沿用写事务锁。
- APP 会员中心 ViewModelStore 移至主 ViewModel 持有，页面离开和旋转不再销毁业务 ViewModel；退出及更换账号清理。不能据此承诺进程被系统杀死后恢复所有输入。
- serverdata.md、secrets 和上传目录加入忽略规则，未查看或提交凭据。
