# 会员达标时间选择器

对标只读检查确认 `game_addiction_time` 为 datetimepicker 文本框，启用当前时间，格式 `YYYY-MM-DD HH:mm:ss`，语言 `zh-cn`。证据：`member-date-control.json` 和 `member-date-picker.json`，位于 `visual-baseline/reference-verified`。

本地现已接入同系列 Eonasdan Bootstrap datetimepicker，资源保存在本地 vendor 目录。保留手动输入，表单仍提交日期字符串，不引入浏览器时区转换。切换页签或窗口状态隐藏日期弹层；关闭、重新打开或导航时销毁旧实例；表单重置会同步组件内部日期。

本地存储契约补齐：创建和更新限制为数据库列的 64 字符容量，PATCH 拒绝 null，清空用空字符串。此前 null 可能触发数据库非空错误，超长值在 SQLite 和生产数据库中可能出现不同行为。隔离 API 测试验证无效请求不同时保存其它字段、时间字符串原样往返、列表与详情一致及清空；浏览器测试验证清空后提交空字符串。这是按本地数据库约束修复输入契约，不构成对标服务端日期校验规则的证据。

`verify_member_date_picker.py` 使用浏览器隔离接口验证：选择日期保留时分秒、跨页签草稿、重置内部状态、手动输入只提交变化字段、关闭清理。会员字段及编辑生命周期回归通过。

尚未证明：弹层逐像素一致、对标服务端对非法日期的处理、所有日期/时间面板和键盘路径。当前结论仅为补齐缺失的日期选择交互，不代表整个基础页签验收完成。

后续增加时间主面板、小时、分钟和秒网格的同值采集；通过 `PARITY_DATE_PANEL=time|hours|minutes|seconds` 选择。修正时间表格 5px 内边距、数字字号及上下箭头按钮布局。浏览器测试增加选 23 时、45 分、50 秒以及递增一秒，验证日期和所选值保持一致。各面板像素结果在离线报告中单独列出，不以交互测试替代视觉验收。

新增同日期截图对比：两端弹层实测尺寸均为 247×284.5 CSS 像素，裁剪图片为 248×285 像素，差异像素占比约 0.532%。修正了字体、边框、底部图标布局，补齐对标的“回到今天”和“关闭”按钮。结果位于 `visual-baseline/fixtures/member-date-picker`。复现时设置 `PARITY_MEMBER_TAB=basic` 和 `PARITY_DATE_PICKER=1` 后运行对比脚本。此指标只比较弹层内部，不验证它相对整个表单的定位。
