# 会员编辑页签同数据对比

采集脚本：`scripts/compare_member_lottery.py`。通过环境变量 `PARITY_MEMBER_TAB` 选择 `lottery`、`download` 或 `agent`，登录凭证通过 `PARITY_USERNAME`、`PARITY_PASSWORD` 提供。

三组均使用 1920×1080 视口、800×600 弹窗，两端填写相同模拟值。对标登录后拦截业务写请求，只操作浏览器表单；本地会员接口使用隔离响应。截图不包含隐藏基础页签中的真实身份信息。

最新采集结果：

| 页签 | 差异像素占比 | 采集字段位置与尺寸 |
| --- | --- | --- |
| 抽奖设置 | 0.8123% | 一致 |
| 下载设置 | 0.5956% | 一致 |
| 代理设置 | 0.5969% | 一致 |

代理页修正前差异为 3.2088%。本轮修正了代理单选行高度、选项间距和颜色，以及三个页签共用的底部按钮边框、字体和尺寸。字段及窗口交互回归通过。

完整数据、字段几何值、截图和差异图分别位于 `visual-baseline/fixtures/member-lottery`、`member-download`、`member-agent`，并已加入离线汇总报告。

差异像素阈值为任一 RGB 通道差值超过 10，分母包含窗口空白区域；该指标不是全站完成率。仍有像素差异，基础信息页签尚无完整同数据截图验收；服务端抽奖、分佣和下载安装行为也不由这些截图证明。
