# 2026-10-12 复查建议实施

## 已修改

1. 奖励台账新增可空 `coin_log_id`。新广告奖励、分佣在同一结算事务内写入准确金币流水 ID，不拆分资金事务。
2. 对账增加广告关联、奖励受益人、入账类型、会员、游戏、金额以及重复引用检查；已结算广告检查入账流水，启用策略快照的广告还检查奖励台账；孤立分佣流水报告异常。
3. 历史奖励记录使用广告会话的流水 ID；历史分佣通过会员、游戏、301 类型和完整广告业务标识匹配，零条或多条均报告，避免猜测关联。迁移不批量改写历史台账。
4. 保存策略时在游戏行锁下读取旧配置并比较结算字段。公告及入驻/风控开关等独立字段变更不重新校验原有奖励密钥；修改结算字段或启用可信奖励仍需校验。广告请求校验不放宽。
5. Android 后台工作任务增加代次；取消会使旧代次失效并清除任务引用。旧任务的 finally 不能再写入新任务冷却时间。
