# 会员日期与分页复验

日期筛选原先把日期直接当作 UTC 零点，漏掉北京时间当天凌晨并混入次日凌晨。现在 `create_time` 的单日及日期范围按北京时间自然日转换成 UTC 闭开区间；日期溢出返回 422。会员表格的时间字段复用北京时间格式化，避免显示原始 UTC 字符串。

分页原先只根据本页是否少于 20 条判断下一页，恰好满页的末页可以进入空页。现在使用总记录数；刷新后总页数减少时回到最后有效页。

证据：

- `test_member_date_filter_uses_beijing_day` 先复现失败，再验证午夜前一秒、午夜、当天最后一微秒及次日午夜，并与带 `+08:00` 的时间范围请求比对。
- `test_member_registration_filters` 保留注册 IP、日期范围和无效日期检查，样本明确使用北京时间对应的 UTC 存储值。
- `verify_member_date_display.py` 在北京和洛杉矶两个浏览器时区验证相同的表格显示和筛选参数。
- `verify_member_pagination_boundary.py` 使用 20、40、3、0 条模拟记录验证末页、缩页和空结果。

这些证据证明本地显示和筛选口径一致，不等于会员全页面视觉、全部交互或对标后端规则已完成验收。测试不写实际业务数据库。
