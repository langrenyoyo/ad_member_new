## 已实现

1. 广告列表新增广告品类、名称、看广行为。名称来自 SDK 元数据或人工复核，品类来自人工复核；缺失显示未知，不根据名称猜测分类。
2. 提现按同会员、同游戏上次成功到账至本次申请之间的完整北京时间自然日核检；首次提现从注册后的首个完整自然日开始。非零点的到账当天及申请当天不纳入整日报表。任何一天报表或用户价格不完整、币种混合均待核检，不能作为整笔提现收益的精确归因。后台展示日期范围。只有确认 succeeded 的支付订单及其 transferred_at 用作成功提现边界，历史仅审核通过记录不作成功凭证。差异率为 `(后台收益 - TAKU收益) / 后台收益 * 100%`，严格超过配置阈值标记。
3. 用户确认多层代理分别获得代理比例分佣。新广告 v3 快照保存全部上级代理，A→B→用户时 A、B 均获得奖励乘代理比例；其他等级仍取最近上级，全应用代理仅在无上级代理时兜底。旧 v2 广告仍按原单代理快照结算。多层代理使实际总分佣随层数增加，配置比例之和不代表每条链路的总支出上限。迁移 e938 将历史 V2 合并为团长，历史快照与流水保留。
4. 账号、短信新用户、微信新用户注册强制本游戏有效团长/代理邀请码，事务内绑定 Member 和 Enrollment 的上级。APP 三个入口传入邀请码。旧用户登录不重新要求邀请码。
5. 白名单会员可设置独立最小/最大金币。区间须同时为空或同时有效，支持最多六位小数；部分更新也校验合并后的区间。金额在广告申请时随机并快照，优先于全局倍率、奖励开关、单次上限。设备信号、冷却、限次、设备校验及重试统一豁免；账号停用、签名验证、真实回调仍有效。
