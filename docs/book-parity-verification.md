# 教程页核验（2026-09-18）

本轮补齐教程列表和详情交互；原图仍缺失，不能宣称教程或全站一比一完成。入口：`http://localhost:3000/#book`。

## 参考证据

`inspect_book_parity.py` 登录参考站后只读访问 `/book`、`/book/index` 和 `/book/detail/ids/{id}`，拦截业务写入。截图、导出和正文比较均使用虚构记录。原教程数据只在内存比较，本地两篇记录与新读取的参考记录完全相等，包括标题、正文 HTML、创建和更新时间；报告仅存计数和相等结论。

参考列表没有标题搜索，只有创建/更新时间筛选；默认隐藏更新时间列。两时间列可排序，默认 Id 倒序；支持行选择、全选、卡片、列显示、六格式导出、10/15/20/25/50/All、跳页与首尾循环。详情是 800×600 独立文档窗口，没有遮罩，背景列表可用，可以打开多个详情。Esc 关闭最上层窗口；参考存在关闭动画，等待 500ms 后再判断，100ms 检查会误判仍未关闭。

|---|---|---|

五列宽一致。默认、选中两组共 12 个导出中，11 个内容一致。全量参考 XML 遇到 `<>&` 无法解析，本地正确转义；选中不含特殊字符的单行 XML 一致。操作列和选择列不导出，隐藏列和选中范围被保留。

## 实现与验证

- 列表复用 `mountGameUserTable`，保留日期筛选、排序、列显示、卡片状态；刷新不清空筛选。行选择、全选、选中导出、All 分批和数据漂移检测已验证。
- 新增认证只读 `/api/v1/tutorials`、`/api/v1/tutorials/{id}`。以现有 `public/target-book.json` 为目录源，未新增数据库表或自动同步任务。分页前先筛选排序，时间边界按 UTC 比较；列表不传正文。文件缺失/损坏返回 503，合法空目录返回空列表，未知 ID 返回 404。
- 详情按参考使用独立文档。DOMPurify 3.4.15 去除脚本、事件和危险链接；iframe 禁止脚本，保留正文样式、文字和图片。库与许可证位于 `public/vendor/purify.min.js`、`public/vendor/DOMPurify-LICENSE`。窗口支持拖动、最小化/还原、最大化/还原、显式关闭与最上层 Esc；正文获得焦点后 Esc 同样生效。
- 请求失败可重试；关闭窗口或切页后取消请求，迟到响应不覆盖新页面。1920/1024/390 视口检查通过，固定图片确实加载；这些图片测试不代表九张真实原图已恢复。
- 两个最小化窗口按参考 181px 间距停靠；窄屏停靠换行以保持可操作，此窄屏行为未完成参考对照。
- `python -m unittest discover -s backend/tests -v`：75 项通过，隔离 SQLite。新增目录日期/排序/分页/详情/鉴权和损坏目录/空目录区分测试。
