# 广告释放、标签与资金精度实施记录

## 后台使用

在「APP 业务规则」加载游戏，启用自定义奖励。

- 固定 ECPM：沿用后台固定值；与分段释放分开。
- 分段释放：选择可信人民币 ECPM，输入阈值及百分比，例如 `50,100` / `200,70`。按本次广告 ECPM（元/千次）计算，阈值包含上限，超过末档沿用末档。分段比例替代平台比例，允许 0–1000%；再应用白名单倍率及奖励上限。可使用服务端试算，不写入资金。
- 标签统计：默认最近 100 次已展示广告、最少 10 个样本、严格超过 50%。窗口、最少样本和阈值可配置；示例不是上线运营建议。未知广告计入分母，未复核内容不推断分类。
- 会员档案的每条广告可由超级管理员复核名称、类别和依据。版本冲突拒绝覆盖，前后值及管理员写入审计。支持将错误分类纠正为未知。
- 标签固定金币：默认关闭。可为游戏、交友、金融、电商及其他标签填写金币；空白沿用 ECPM，0 表示零金币。固定金额覆盖 ECPM 比例和白名单倍率，但仍受单次奖励上限约束。分佣按最终用户奖励另计。即使启用固定标签奖励，可信 ECPM 模式仍须满足原有证明校验。
- 领取广告时保存策略、标签统计、白名单和分佣归属快照。以后修改分类或配置只影响新广告，不回溯扣减已完成奖励。当前标签基于人工复核记录，不自动认定异常或封禁。

## SDK 元数据

TAKU 回调新增展示、点击、奖励、关闭四个阶段的元数据采集。保存平台、广告源、格式及扩展字段中可能存在的标题、应用名、素材 ID；仅保存其他扩展字段的键名，不批量存储原始值。客户端跨账户保护和后端会话归属校验均保留；每会话每阶段幂等。

标题候选字段不是广告平台保证返回的统一字段。数据明确标为客户端上报，不能当作平台核减证明，不能自动决定分类或结算。未返回名称时显示未知。OCR/AI 尚未接入，需要可用、获授权的素材来源和真机样本；不会读取其他应用或伪造识别结果。

## 资金与迁移

- 会员余额、冻结资金、累计金币、金币流水、APP 会话奖励改为 Numeric(24,6)。广告入账、分佣、提现冻结/退回/完成、调账和清零使用 Decimal。
- 旧 API 保持 JSON 数字格式，转换仅在展示/传输边界；大金额的旧客户端显示仍受浮点精度限制。调账保留原操作上限。
- 历史广告报表、旧提现展示价格和补贴展示字段不属于本次钱包迁移，仍有 Float；不能将本次称为全库金额类型统一。
- 新迁移顺序：e931 分类复核表 → e931b 缺失 APP 基础表及字段修复 → e932 钱包精度迁移。
- e932 保存各行原值与六位小数目标值到 `wallet_decimal_migration_values`，截断超过六位的小数，不伪造调账流水。历史分行截断可能产生累计对账差异，须按归档核对。
- 部署前停止资金写入并备份，在副本运行 `python -m alembic upgrade head`，核对会员余额、冻结提现及流水后再上线。迁移不提供会丢精度的自动降级，应恢复经过核对的备份。尚未操作现有业务数据库。
