# 禾合 1.0.15：后台更新策略

后台进入 APP 业务规则，加载游戏 ID 1，底部 APP 版本更新可设置：启用更新、用户选择/强制更新、包名、versionCode、版本名称、HTTPS 下载地址、说明。保存独立于奖励规则，不改变分佣设置，仅超级管理员可修改并记录操作日志。

客户端在启动授权后读取 `/api/app/v1/app-update?game_id=1`。启用、包名匹配、versionCode 高于当前版本、下载地址为同服务域名 HTTPS 时展示更新弹窗。强制更新不显示跳过按钮，返回/点击外部不关闭，打开浏览器后返回仍保留弹窗；正常业务页面和开屏在提示结束后进入。检查网络失败时允许进入，本机制是客户端启动提示，不是服务端旧版 API 封禁。

本次版本 code 16，版本名 1.0.15，初始发布使用可选更新。后续发布必须先上传同签名 APK，再设置正确的更高版本号，最后按需选择强制模式。仅调整模式但没有更高版本，不会弹窗。

兼容限制：1.0.13/1.0.14 仍读取静态更新清单，仅支持可选更新；1.0.12 更早没有更新检查。需要先安装 1.0.15，之后才能受后台强制更新策略控制。

验证：后台更新 API 的默认值、权限、两种模式切换、HTTPS 校验及无缓存响应已通过自动化测试。客户端需以低版本配合更高版本配置，在真机确认不可跳过、下载安装及取消行为；本次无连接手机，不伪造线上高版本强制更新测试。
