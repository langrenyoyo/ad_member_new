# 开发计划

## 1. 目标

项目目标是对 `https://ad.leadink.cn/` 后台进行整站一比一复刻。复刻范围包括导航、菜单、多标签页、列表字段、筛选项、按钮、弹窗、状态文案、分页、导出、审核和风控操作；后端使用 FastAPI + SQLAlchemy + PostgreSQL 实现等价业务能力。

## 2. 整站开发排期

| 阶段 | 内容 | 预估 |
|---|---|---|
| 对标盘点 | 登录后逐页确认导航、菜单、字段、筛选、按钮、状态和弹窗 | 2 - 3 天 |
| 数据建模 | 主体、游戏、会员、广告、提现、补贴、收益和风控模型 | 2 - 4 天 |
| 核心接口 | 认证、列表、详情、CRUD、审核、导入导出和统计接口 | 5 - 8 天 |
| 前端复刻 | 页面布局、多标签、筛选、表格、弹窗、分页和操作反馈 | 5 - 8 天 |
| 联调回归 | 权限、数据口径、异常、兼容字段和浏览器回归 | 2 - 4 天 |
| 部署上线 | PostgreSQL 迁移、环境配置、日志、备份和上线检查 | 1 - 2 天 |

合计：17 - 29 天

## 3. 模块交付顺序

1. 登录目标后台，完成整站菜单和页面盘点
2. 冻结每个模块的字段、筛选、按钮、状态、权限和接口契约
3. 优先完成广告列表及其详情、统计、导入、导出和告警
4. 完成主体管理、游戏管理和会员管理
5. 完成提现审核、补贴申请、收益管理和金币流水
6. 完成白名单、风控历史、设备风控和个人资料
7. 进行整站联调、权限回归、数据校验和部署验收

## 4. 排期说明

- 以上为单人全职开发、已有基础工程可运行、目标页面可正常访问时的估算。
- 若目标后台存在未公开接口、复杂异步任务、第三方支付或大规模历史数据迁移，需在对标盘点后重新评估。
- “一比一”指页面结构、交互和业务结果对齐；后端代码、数据库、密钥、私有数据和未授权资源均采用自研或授权方案。
- 目标页面登录态、权限范围和数据量会影响盘点与验收时间。

## 5. 阶段验收

| 阶段 | 验收结果 |
|---|---|
| 对标盘点 | `docs/benchmark.md` 中每个页面都有目标路径、字段和交互记录 |
| 接口完成 | 页面所需列表、详情、保存、删除、审核和导出接口可调用 |
| 前端完成 | 目标页面可从菜单进入，布局、状态和操作反馈一致 |
| 联调完成 | 筛选、分页、权限、错误提示和空数据状态通过回归 |
| 上线完成 | PostgreSQL 迁移、环境变量、日志和备份检查通过 |
