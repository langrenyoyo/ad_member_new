# 会员同数据列表复验

新增 `compare_members_fixture.py`，对真实对标和本地页面注入相同三条会员记录。样本刻意区分昵称、实名认证姓名和支付宝姓名，并覆盖 V0/V1/V2、状态与白名单开关、金币及时间字段。

依据真实 `members-controller.js` 和渲染表头，修正默认列顺序与字段：移除默认可见的昵称/实名认证姓名，使用 `receive_name` 显示支付宝姓名；列名匹配账号、VIP、可用金币；单 APP 行为入口移到操作列。列集合不再依赖首条数据是否碰巧包含字段。补齐 VIP 颜色和筛选、表格间距。

浏览器对照断言本地与对标可见表头顺序相同，并确认三条记录均显示支付宝姓名而非实名认证姓名。同数据差异像素占比 11.1518%，平均 RGB 差异 5.07742，仍有明显工具栏、操作列、筛选控件和列宽差异，不标记完成。

数据、双端截图与指标已纳入 `visual-baseline/fixtures/index.html`。未写入业务数据库，也未隐藏不同权限的按钮来降低截图差异。

后续已接通 ID、累计金币、可用金币、冻结金币和创建时间排序，使用后端排序参数而非仅排序当前页。`verify_member_sorting.py` 验证五字段升降序、切换排序回首页、筛选/主体范围保留；分页边界和异常恢复回归通过。截图对照按去除装饰性排序箭头后的表头文字核对列顺序；最新图像指标以 `fixtures/members/report.json` 为准。

工具栏补充单条选择编辑和普通搜索切换；全选同步行选择，多选/未选禁用编辑，收起筛选保留未提交值。发现并修复通用编辑弹窗被 Bootstrap `.modal` 默认 display 隐藏的冲突，表单和关闭按钮现可见。`verify_member_toolbar.py` 覆盖全选/部分选择、单条编辑打开与取消、模拟 PATCH 保存、空结果、筛选收起刷新及离页清理；没有实际业务写入。异常恢复回归通过。该修复不证明编辑表单所有字段及权限已与对标一致。
