# 微信登录反馈修复 1.0.16

2026-11-13 16:27（北京时间）的四次 1.0.15 微信登录请求均到达 `/api/app/v1/auth/wechat`，返回 422；请求中的邀请码为空。线上游戏 238 的 `require_registration_invite` 为 true。该接口在兑换微信授权码后为新会员校验邀请码，缺失时拒绝注册。

此前登录失败文字位于可滚动页面中部，用户停留在底部微信按钮时可能看不到。1.0.16 将登录错误同时显示为必须手动关闭的弹窗；空邀请码对应的错误明确说明首次登录须填写本应用团长或代理的6位邀请码。微信按钮显示处理中状态，按钮下显示首次注册要求。

不改变现有邀请注册规则，已有微信账号仍可不填邀请码登录。不将空邀请码作为客户端统一拦截条件，以免阻止已有账号。

版本号 1.0.16，versionCode 17。验证范围为 Android 单元测试、Lint、正式签名构建；完整微信登录需真机和有效邀请码验证。
