# 登录后引导与恢复修复

- 手机号用户可在强制支付宝引导页获取短信，验证当前账号手机号并设置密码，无需退出登录。新增 `POST /api/app/v1/auth/sms/password`；按当前会员、游戏和验证码绑定校验，验证码一次性使用，密码两次输入一致且满足强度要求。
- 首次规则未知、明确 401/403 拒绝和未完成要求仍阻断；已加载规则的暂时网络故障不再替换整个页面。每次回到前台立即检查使用权限和刷新规则，前台每分钟重试，离开前台取消定时刷新任务。
- 设备冷却页展示服务端恢复时间，并提供钱包入口查看记录及确认原申请；后台仍决定是否允许请求，不在客户端解除风控。
- 普通邀请码、支付宝姓名及账号输入按用户保存重建状态；密码和短信验证码不持久化。

新增三个 JVM 门禁决策测试；后端策略测试增加当前会员短信设密、其他会员拒绝、重复验证码拒绝校验。测试使用模拟短信记录，不代表真实短信或 Android 权限设置真机验收。

部署：先部署新增短信设密接口及引导豁免路径，再安装新 APK；不需要新增数据库迁移。未操作线上服务。仍待后续处理普通微信登录无回调超时、短信登录方式整理，以及完整业务操作的会话隔离。

验证结果：Android 构建、26 项 JVM 测试和 Lint 通过；后端 9 项会员策略测试通过。冷却期恢复入口仍依赖有效登录凭据；Token 过期且后台禁止刷新时，需待冷却结束或另行设计受限恢复凭据。未进行真机验证。
