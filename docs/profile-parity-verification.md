# 个人资料页核验（2026-09-18）

本页已完成本轮固定数据对照和本地交互回归，不代表全站一比一完成。入口：`http://localhost:3000/#profile`。

## 参考与方法

- 参考路由 `/general/profile`，通过 `inspect_profile_parity.py` 登录后只读访问。所有业务写请求被拦截；表单替换为虚构账号，日志响应为三个虚构记录，不保存真实账号或操作日志内容。
- 内容区 1690px，同三条记录、字体加载完成后比较；另用 225 条记录对照分页。数据、截图、六格式下载及报告在 `visual-baseline/fixtures/profile/`。
- 原 `verify_profile_browser.py` 指向旧端口并直接修改账号，不用于本次核验。新 `verify_profile_parity_browser.py` 拦截全部 API，所有写入只发生在内存响应中。

## 行为与数据

- 用户名、手机禁用；昵称、密码可编辑。密码留空不修改，保存后清空输入。重置恢复上次保存的昵称与头像，上传预览不会提前修改账号头像。
- 头像允许 PNG/JPEG/WebP/GIF，最大 2MB、4096px。后端解码、去元数据并规范化为 PNG，随机文件名保存到 `MEMBER_IMAGE_DIR`。任意已登录后台账号可上传自己的头像，会员头像接口权限保持原样。
- 保存头像只允许默认地址或已存在的规范化本地图片路径，拒绝外部地址、脚本地址和不存在的文件。保存后侧栏、顶部与刷新后的头像一致。
- 提交锁定、失败后恢复、取消上传、重复提交、切页后的迟到读/上传/保存响应均有模拟测试。补修隐藏输入默认值变化导致的头像重置错误，以及启动账号查询迟到后覆盖已保存昵称的问题。
- 日志固定当前后台账号范围；全局搜索、仅时间排序、10/15/20/25/50/All、跳页和首尾循环、列隐藏与卡片切换均已验证。All 与导出按 200 条分批请求，检测总数漂移和重复 ID。
- 按参考保留可编辑的路径输入与新窗口链接；IP 显示搜索链接样式，但参考点击不触发查询，本地同样不触发。
- 五种导出 JSON/CSV/TXT/Word/Excel 与参考内容一致。按参考排除第一可见列，路径列 JSON 为数值 0，其他格式为空。参考 XML 未转义 `<>&` 而无法解析，本地使用 XMLSerializer 输出有效 XML，此差异有意保留。

参考没有授权实际保存/上传，因此昵称长度、密码长度、头像格式/大小限制、保存提示及真实上传端点规则未证明一致。本地保留昵称 1–128 字、密码至少 10 字的既有策略。日志采集覆盖与参考后台全量操作埋点仍待核实。头像共享存储、未引用文件清理不在本次实现范围内。
