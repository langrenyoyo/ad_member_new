# 会员筛选异常与请求顺序

会员通用列表的请求以前直接抛出错误；无效创建时间或服务失败时，点击筛选的异步事件没有统一错误处理。相同页面地址下，较早发出的请求也可能覆盖较晚的筛选结果。

现在加载失败显示可重试的错误区域，已有会员筛选表单保留输入。每次页面加载递增请求代次，旧结果不再覆盖最新结果；旧错误也不会覆盖新页面。有效页恢复逻辑和主体地址约束保留。

`verify_member_request_recovery.py` 用浏览器模拟 503、日期 422 和延迟响应，验证首次失败重试、错误输入保留、重置恢复以及新响应优先。会员分页边界和主体导航范围回归通过。所有请求均使用浏览器模拟数据，没有业务写入。

这不证明对标错误提示样式或整个会员模块一比一；对标异常状态仍需要独立可复现证据。
