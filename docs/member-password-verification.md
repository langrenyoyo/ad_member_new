# 会员密码修改验证

修正了两处本地问题：密码哈希现在在权限、非空字段及会员范围校验之后执行；新建会员的支付密码框此前为普通文本，现与登录密码一样使用 password 类型和 new-password 自动填充提示。

`test_member_passwords_are_hashed_and_not_serialized` 使用隔离数据库验证：

- 修改响应、详情和列表均不包含明文密码、密码哈希或盐。
- 风控角色越权和无效字段请求在哈希之前被拒绝。
- 两组密码同时提交但一项校验失败时，两组原值均保留。
- 单独修改登录密码使用新盐，支付密码哈希与盐保持不变。

`verify_member_edit_fields.py` 验证新建表单两种密码输入均为遮蔽类型，并继续覆盖编辑字段和变化值提交。

这些验证证明本地存储和接口行为，不证明与对标服务器密码策略完全一致，也不代表会员端登录或支付认证流程已验收。对标服务端的密码长度、字符及空值规则仍待授权测试证据。
