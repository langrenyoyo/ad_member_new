# 设备拦截记录

后台入口：风控管理 → 设备拦截记录，/admin/#device-blocks。

支持游戏ID、会员ID、拦截类型、起止时间过滤及分页；显示北京时间、会员昵称、设备编号、中文原因、风险信号、额度和限制截止时间。仅超级管理员和风控角色可查询。

覆盖每日限次、24小时额度/冷却期、客户端设备风险信号、校验凭证缺失/过期/复用、校验过频、校验服务异常及登录换设备限制。未识别设备不伪造设备编号，校验异常不标记为作弊。

通过带上下文的异常在请求业务事务回滚后写入 ad_flow_logs，避免回滚丢失事件。不存储SDK令牌或密码。读取已有 device_limit_rejected 历史记录；其他未记录的历史拦截无法补还原。不改变风控放行规则。

验证：设备风控和会员规则52项通过；新增日志持久化/权限/过滤/敏感信息及微信登录相关17项通过；冷却期补充测试1项通过。前端脚本语法检查通过。
