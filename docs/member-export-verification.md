# 会员导出

对标会员页运行时导出配置保存在 `visual-baseline/reference-verified/member-export/options.json`：JSON/XML/CSV/TXT/MS-Word/MS-Excel，未选择记录时导出全部，忽略复选框和操作列。公共表格控制器会按勾选状态切换导出范围。

本地新增对应六格式菜单，复用现有 tableExport 组件。未勾选时按当前查询条件、排序及主体范围，以每批 200 条获取全部记录；勾选时使用当前页面已选择的记录。捕获导出开始时的列配置，排除操作列，仅导出显示的数据列，卡片标签不会混入内容。图像及图标开关列保持空文本，不把按钮标签冒充导出业务值。

导出期间防止重复启动；总数改变、重复 ID 或分页提前结束会显示错误，不下载不完整文件。原面板离开或刷新后取消结果下载。XML 使用 DOM 序列化以保留中文、引号及 `<>&`。这些格式沿用现有插件格式，Excel 不是额外实现的 xlsx。

`verify_member_export.py` 通过：205 条筛选/主体范围内 CSV、第二批 offset=200、隐藏创建时间列、无操作列、卡片模式选中记录的六种真实下载、XML 反解析、选中导出无新列表请求、分页总数变化拒绝下载、离开页面取消在途导出。`verify_member_toolbar.py` 通过；两个修改的 JavaScript 文件语法检查通过。默认列表、卡片及日历截图重新生成。

尚未逐格式对比对标导出文件；对标跨页勾选保留、本地当前页选择，以及并发更新但总数不变的导出一致性仍需验收。本项不代表会员模块或全站已完整一比一。

## 六格式双端下载核验及修正

`compare_member_export_fixture.py` 已对同一组三条模拟记录，分别下载全部/勾选一条的六种格式文件（共 12 组），证据和 `comparison.json` 存放在 `visual-baseline/fixtures/member-export`。对标列表请求均用浏览器响应替换为模拟数据，没有写入对标业务数据库。

实际下载推翻了上文“图标开关导出空文本”的假设：对标会在 CSV/JSON 等值中保留 VIP span 和状态 i 标记，Word/Excel 中也保留对应结构，XML 中则是子元素。本地已按实际文件修正；只对程序生成的徽标/开关标记建立 XML 子元素，业务文本仍经 DOM 文本节点转义，保持特殊字符合法。

修正后 12 组均通过：CSV/TXT 按分隔符解析后相等；JSON 完整对象相等；XML 重新序列化整个根节点后相等，包含表头、行、子元素和属性；Word/Excel 文件文本相等。脚本现在在任一对比不一致时失败，不仅打印结果。

`verify_member_export.py` 的 205 条数据、六格式所选记录、XML 特殊字符、隐藏列、在途取消、总数变化拒绝下载回归通过；共享 XML 工具改动后主体六种格式导出回归也通过。

当前双端一致的证据只覆盖默认显示列、三条固定普通值及一次单选。隐藏列导出、跨页选择、特殊值在对标中的全部语义和大数据并发状态仍需独立对比，不能扩大为全站功能/数据完成结论。

## 隐藏列及 JSON 类型核验

对比脚本新增 `--hidden` 模式，打开上级 Id、上级账号、代理商名称、昵称、达标状态/时间、兑换、最后登录设备/IP/时间共 10 个隐藏列。两端使用同源字段映射，包含上级 Id 为 0、登录时间的 UTC/Unix 表示及带前导零的账号 `000123`。独立证据目录为 `visual-baseline/fixtures/member-hidden-export`。

初次隐藏列核验发现 JSON 类型差异：对标上级 Id 为字符串 `"0"`，本地被导出插件转换为数字 0。已在构造导出表时保留数值形式的可点击字段的链接结构，使它们继续作为字符串输出，避免数字账号丢失前导零。普通文本继续以文本节点输出，保持 `<>&` 等字符完整；不直接把业务文本作为 HTML 插入。

`verify_member_export.py` 的特殊字符及 205 条导出回归通过。头像列未纳入本轮，跨页选择及并发一致性仍待核验。各次最终对比以目录中的 `comparison.json` 为准。
