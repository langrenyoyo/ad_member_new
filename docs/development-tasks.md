# 开发任务清单与差异分析

日期：2026-08-30  
目标：按 `https://ad.leadink.cn/` 整站一比一复刻需求，拆分可执行开发任务。

## 1. 当前基线

当前项目已具备 FastAPI + SQLAlchemy + PostgreSQL 目标架构，并已有静态前端后台壳。后端覆盖认证、主体、游戏、会员、广告、提现、补贴、金币流水和风控列表；广告模块已覆盖列表、详情、统计、导入、导出和告警能力。

下一步重点不是继续扩文档，而是把“基础可用”推进到“目标站一比一对齐”：字段、筛选、按钮、弹窗、状态流转、权限和验收截图逐项补齐。

## 2. 优先级定义

| 优先级 | 含义 | 处理要求 |
|---|---|---|
| P0 | 影响核心验收或已明确不一致 | 第一阶段必须完成 |
| P1 | 目标站需要逐页对齐的主要模块 | 第二阶段完成 |
| P2 | 上线增强、审计、性能和运维 | 第三阶段完成 |

## 6. 第三阶段 P2 开发任务

目标：上线前增强安全、性能、审计和运维能力，预计 4-8 个工作日。

| 编号 | 任务 | 交付结果 |
|---|---|---|
| P2-01 | 登录安全增强 | 登录失败限制、验证码或二次校验按目标站确认 |
| P2-02 | 操作日志 | 记录新增、编辑、删除、审核、导入和导出操作 |
| P2-03 | 数据库索引优化 | 针对广告、会员、提现和风控高频查询加索引 |
| P2-04 | 导入性能优化 | 大文件行数限制、分批入库、错误结果下载 |
| P2-05 | 导出性能优化 | 大导出异步任务或分页导出方案 |
| P2-06 | 生产配置 | 禁用演示数据、强密钥、环境检查、日志级别 |
| P2-07 | 备份恢复 | PostgreSQL 备份、恢复演练和上线回滚说明 |
| P2-08 | 浏览器验收 | 桌面常用浏览器和不同分辨率截图验收 |

## 7. 建议立即开工顺序

1. 修广告列表前端：操作列、详情按钮、导入按钮、导出按钮。
2. 修提现和补贴后端：重复审核、重复转账限制。
3. 补审核操作字段：审核人、审核时间、转账时间。
4. 增加个人资料页面：查看账号、修改密码。
5. 补角色权限测试和前端按钮权限。
6. 更新 `docs/benchmark.md`，把广告模块从“已确认”推进到“待验收”。
