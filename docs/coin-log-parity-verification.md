# 金币流水对照核验（2026-09-18）

本轮恢复主金币流水的排序、筛选开关、日期弹层、列选择、卡片视图、六格式导出和完整分页，保留认证分页游戏/代理商搜索选择器。相关实现为 `public/coin-logs.js`、`public/coin-logs.css` 与共享 `public/game-userdata.js`。本页是查询与导出视图，本次没有新增或修改真实金币业务记录。

## 参考证据

`inspect_coin_log_parity.py` 登录后阻止非 GET/HEAD 及已知业务变更 GET；对金币流水 AJAX 请求注入模拟记录，包含分页关闭时没有 limit 的全量导出请求。保存的数据均为模拟账号、游戏、代理商和金额。

- 12 个可选数据列，广告状态默认隐藏，默认显示 11 列；没有勾选列。Id 默认降序取数但没有表头排序按钮；金额前/变动/后及创建时间可排序。
- 筛选默认展开，广告状态默认为正常，日期为北京时间当天。普通重置恢复这两个默认值。
- 会员 ID 为精确匹配；用户账号和代理商名称使用 LIKE；游戏名称使用精确名称匹配。点击类型或广告状态标签也会筛选。
- 默认每页 10 条；10/15/20/25/50/All、页码、跳转、首尾循环、列选择、卡片视图和六种导出入口均存在。
- 卡片标题占 30% 宽，没有冒号；空备注行隐藏，数值零保留。
- 参考默认导出忽略首列。本地在此页按同样规则跳过当前首个可见列，正常状态不导出 Id；其余共享表格不启用此配置。

证据位于 `visual-baseline/fixtures/coin-logs/`，包括参考控制器、列及控件几何、请求、模拟记录、截图与导出文件。参考后端生成流水、金币汇总和权限归属的完整规则仍不可由这些前端证据证明。

## 实现与验证

主页面使用已有共享表格，增加可选的状态保留、重置回调和导出格式回调；已有调用方继续使用原默认行为。离开页面会销毁控制器并取消读请求/导出，返回后保留筛选、排序、列与视图状态。请求失败保留原表格；All 分批取数，每批最多 200 条，并检查总数变化和重复 ID。

新增 `game_name_exact` 和 `agent_name` 查询参数：前者精确匹配，后者按字面包含关系匹配，百分号与下划线不充当通配符；名称条件与已有 ID/会员范围取交集。原会员行为使用的 `game_name` 包含搜索未改变。返回隐藏的 `game_ad_status` 列值；不存在关联代理商时返回未知值，不伪造正常状态。汇总对完整筛选结果求和，不以当前页替代。

`verify_coin_parity_browser.py` 使用 225 条浏览器隔离记录验证：默认筛选/重置、游戏名称与选择器 ID 模式切换、代理商名称搜索、会员及标签点击、无效日期拒绝、日期弹层、双向排序及排序图标、分页/All、隐藏列、卡片视图、路由返回状态、六种实际文件下载、XML 特殊字符、数据变化拒绝、请求失败重试、旧响应/离页隔离和 1920/1024/390px 布局。

后端新测试覆盖精确/包含匹配、名称与 ID 交集、字面通配符、排序在分页前生效、全量汇总及隐藏状态值。完整后端 66 项测试通过，使用临时数据库；35 个 JavaScript 语法检查通过。共享游戏用户数据、分页、单/多 APP 行为、黑名单和提现搜索选择器回归通过；13 个主路由加载审计通过。共享导出回调修改后重跑游戏用户数据、分页、黑名单及金币流水专项通过。

## 同数据结果

参考以 1690px 内容视口打开，等于本地 1920px 屏幕减去 230px 侧栏；两端按各自面板裁图。默认表格和卡片注入同样三条记录，分页区域使用同样 225 条总数、每页 10 条和第一页状态。

| 状态 | 尺寸 | 差异像素占比 |
|---|---|---|
| 默认表格面板 | 1660×465 | 0.0233% |
| 卡片面板 | 1660×1018 | 0.0236% |
| 多页分页区域 | 1630×56 | 0.2596% |

指标以任一 RGB 通道差值超过 16 计为差异。11 列的浮点宽度逐列相同，主要区域高度与位置已对齐；小量按钮边缘、箭头及分页控件差异仍存在，不能称为逐像素一致。手机只验证可用性与溢出，没有据此证明参考移动端像素一致。

`compare_coin_logs_fixture.py` 实际下载并对照六格式：JSON、CSV、TXT、Word、Excel 五种内容一致（文本统一解码，JSON 按结构比较）。参考类型标签会以 span 标记进入导出，链接文本中的特殊字符保留实体编码，本地按该格式输出。

参考 XML 在普通备注包含 `<>&` 时无法解析（固定样例第 924 列附近），本地使用标准 XML 序列化保留标签结构并转义文本，文件有效。此项明确存在格式差异，未把参考无效文件复制到本地。另在参考站观察到：点击游戏/代理商名称后重置可能仍发送旧隐藏名称条件；本地重置会清除选择器与名称条件。该差异已保留为待确认行为，不声称全部交互完全相同。

以上结果不代表整站一比一完成；其它页面、真实支付及黑名单拦截规则等缺口仍见 `docs/parity-status.md`。
