# 主会员列表开关核验

对标列表中的状态、白名单开关使用 FontAwesome `f205`，字号和行高 26.04px，图标宽 29.765625px。关闭状态水平翻转、颜色为 `#d2d6de`；开启状态颜色为 `#18bc9c`。已替换本地主会员列表原先 30×18px 的 CSS 开关。保留按钮、switch 角色、aria-checked 和键盘焦点提示。

`compare_members_fixture.py` 保存开关计算样式至 `layout.json`，使用同时含开关两种状态的三条生成数据重新采集。当前默认 17 列宽度全部一致，表头 41px、数据行 47px；主列表差异像素占比为 3.0114%。这不是完整视觉一致结论，工具栏和筛选等区域仍有差异。

主列表状态、白名单、兑换开关统一处理提交：等待期间禁用按钮，重复点击不重复发请求，失败保持原状态并恢复按钮，成功重新读取列表。切换路由、列表已重新加载或原按钮被移除时，不使用旧响应刷新当前页面或弹出旧错误。

`verify_member_switches.py` 通过浏览器拦截响应验证三个字段的 PATCH 映射、等待期间重复点击、403 后重试、成功刷新以及导航后的旧响应。未调用对标业务写接口。未重新核验对标服务器的权限和切换副作用，也未将本次主列表改动视为游戏内会员列表已经重新验收。
