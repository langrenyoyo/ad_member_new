# 风控历史对照核验（2026-09-18）

主风控历史页已替换为现有通用表格，恢复默认展开的九项筛选、七类点击搜索、隐藏列、创建时间排序、列选择、卡片、六格式导出和完整分页。实现为 `public/risk-history.js`、`public/risk-history.css`；本轮没有修改共享表格实现。

## 参考证据

`inspect_risk_history_parity.py` 在登录后阻止非 GET/HEAD 和已知业务变更 GET，仅替换风控历史 AJAX 响应。三条模拟事件包含普通文本、空标签、零/非零数值、特殊字符和不同创建时间；225 条模拟总数用于分页局部截图。参考控制器、列配置、请求、截图与下载在 `visual-baseline/fixtures/risk-history/`。

- 14 个可选列，默认隐藏上级 ID 和代理商名称；没有选择列和操作列。行为、风险分数、风险等级均是参考字段，“行为”展示文本，没有行为弹窗入口。
- 默认 Id 降序、每页 10 条，Id 表头没有排序控件。仅创建时间支持排序，参考首次点击降序、再次升序。
- 会员 ID、账号、代理商、标签代码、硬件主 ID 为包含匹配；上级 ID、游戏名称和 IP 为精确匹配。名称链接和下拉选择器使用不同查询值，不能直接将名称替换成一个关联 ID。
- 七类链接为会员 ID、账号、上级 ID、游戏名称、代理商名称、硬件主 ID、IP，均有双端请求证据。标签代码可在表单搜索，但不是点击链接。
- 默认筛选展开、日期为空，工具栏只有刷新及四项表格工具。“重复手机号只显示一个”在参考 HTML 中被注释，不是可见入口。
- 导出不包含当前首个可见列；默认首列为 Id。隐藏 Id 后，首个可见的会员 ID 也被排除。本地按该规则实现，并用实际下载验证。

## 实现与验证

`/risk/history` 新增 `game_name_exact`、`agent_name`，分别使用精确游戏名称和字面代理商包含匹配。原多 APP 页的 `game_name` 包含匹配保持不变。名称、ID、固定会员范围与其它筛选取交集；返回补齐上级 ID 和代理商名称。关联会员缺失时上级 ID 为 null，不伪造关联数据。

新增后端测试覆盖精确与包含匹配差异、名称/ID 交集、固定会员范围、字面 `%_`、父级/代理商返回字段、排序先于分页、北京时间日期边界及无效排序/范围。完整临时 SQLite 后端测试 69 项通过；35 个 JavaScript 文件语法检查通过。

`verify_risk_history_parity_browser.py` 使用 225 条内存数据，拦截所有业务 API，任何业务写请求都会使测试失败。覆盖默认筛选、七类搜索链接、名称/ID 模式切换、重置、无效日期拒绝、日期弹层、日期双向排序、首尾循环、页码跳转、All 分批取数、列显隐、卡片与路由返回状态、六格式全量下载、特殊字符 XML、隐藏首列导出规则、总数变化拒绝、失败重试、旧响应/离页隔离与 1920/1024/390px 边界。

相关游戏用户表格、单/多 APP 行为及行为范围回归通过，13 个主路由加载审计通过。没有执行参考站业务写入或向现有本地业务库插入测试风险事件。

## 同数据结果

参考内容视口 1690px，本地 1920px 屏幕减去 230px 侧栏；字体加载后裁取相同内容面板。比较结果由 `compare_risk_history_fixture.py` 生成。

| 状态 | 两端尺寸 | 差异像素占比 |
|---|---|---|
| 默认展开筛选表格 | 1660×464 | 0.0208% |
| 收起筛选表格 | 1660×320 | 0.0416% |
| 展开筛选卡片 | 1660×1060 | 0.0216% |
| 225 条第一页分页 | 1630×56 | 0.2596% |

以任一 RGB 通道差值超过 16 计为差异；12 个默认列宽逐列相同。局部控件仍有像素差异，该指标不是全站完成度。手机截图 `visual-baseline/verified/risk-history-mobile.png` 仅验证本地布局，没有完成参考手机像素对照。

固定数据的 JSON、CSV、TXT、Word、Excel 五种导出内容一致；文本按 UTF-8 解码，JSON 按结构比较。参考 XML 在标签文本含 `<>&` 时不能解析（样例第 776 列附近）；本地采用已有标准 XML 序列化，保留完整文本并产生有效文件，此差异明确保留。
