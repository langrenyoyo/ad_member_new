# 401、初始化和冷却恢复修复

- 后端为过期访问 Token 返回 TOKEN_EXPIRED；APP 仅对该错误刷新后重试，业务 401（错误密码、验证码）不自动重放。
- 登录初始化与前台规则刷新共用 Mutex；每轮绑定会话代次，已有 bootstrap 不重复初始化广告 SDK。规则先应用到界面，再上传使用统计；统计事件遍历支持协作取消。
- 冷却期已有有效刷新凭据可以换取 recovery Token，允许账户信息、钱包、原提现恢复和退出，禁止 bootstrap 等普通业务。新登录仍受冷却限制，新提现由服务端检查拒绝。APP 重启可恢复账户身份后展示冷却页。
- 普通微信登录增加 120 秒超时，收到事件或退出使旧计时失效。广告流程在异步云 Token 等待前绑定会话，验证云 Token 和申请广告前检查原会话。

部署须同步更新后端与 APP，无数据库迁移。旧后端没有 TOKEN_EXPIRED 错误码，新 APP 不对模糊 401 自动重放。过期/已撤销刷新凭据不能用于恢复；冷却结束后 recovery Token 在下一次刷新时恢复普通权限。

验证：Android assembleDebug、testDebugUnitTest、lintDebug 成功，26 项 JVM 测试通过；后端 10 项会员策略测试通过，新增恢复 Token 允许账户/钱包、拒绝普通业务及新提现测试。未部署线上，未进行真实 SDK、短信或支付联调。
