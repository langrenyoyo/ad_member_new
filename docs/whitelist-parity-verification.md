# 白名单对照核验（2026-09-18）

本轮将白名单列表接入已有游戏用户通用表格，恢复参考列、筛选、操作入口、开关、分页、列选择、卡片和导出。实现位于 `public/whitelist.js`、`public/whitelist.css`；共享表格增加筛选展开状态记忆。后端 `/risk/whitelist` 复用会员查询，强制 `is_white=1`，不创建另一套白名单数据。

## 参考证据

`inspect_whitelist_parity.py` 登录后阻止非 GET/HEAD 与已知业务变更 GET，向白名单 AJAX 注入三条模拟会员；没有修改参考站业务数据。参考控制器、权限、列配置、几何尺寸、截图、请求与下载文件在 `visual-baseline/fixtures/whitelist/`。

- 默认显示选择列及 13 个数据/操作列；头像、上级 ID/账号、代理商、昵称、达标信息、兑换与最后登录信息默认隐藏。默认 Id 倒序，但 Id 表头不可点击排序。
- 筛选默认收起，没有日期默认条件；账号/昵称/代理商名称为包含匹配，游戏名称为精确匹配。游戏和代理商选择器提交 ID，点击名称使用名称条件。
- 参考账号可见单 APP、多 APP、修改金币和编辑；删除、工具栏批量启停、清空金币隐藏。没有独立的白名单新增表单。
- 白名单、启用状态和隐藏的兑换列使用开关。退出白名单修改会员 `is_white`，不删除会员及余额。
- `maintainSelected=false`；参考没有跨页保留勾选。导出有选中记录时使用选中行，否则导出当前查询全部记录；排除选择与操作列。
- 隐藏的最后登录 IP 使用链接样式，但实测点击不展开筛选、不发请求，也没有对应筛选字段。本地目前显示普通文本，此项视觉差异保留。

## 实现与验证

后端复用已有会员查询的父级账号、游戏/代理商名称补全和北京时间日期处理；新增名称筛选及排序白名单。名称和 ID 条件取交集，百分号/下划线按字面处理；分页在排序之后执行。已有会员 PATCH 处理状态与金币修改，保留权限校验。

新增两项后端测试覆盖：固定白名单范围、名称/ID 交集、特殊字符、父级展示、金币排序先于分页、日期边界、无效参数、禁止通过参数扩大到非白名单、角色权限与移除后的余额保留。完整后端测试 68 项通过，使用临时 SQLite；35 个 JavaScript 文件语法检查通过。

`verify_whitelist_parity_browser.py` 使用 225 条内存记录，拦截所有业务读写，验证：

- 默认列/筛选状态、行勾选、卡片勾选、六种选中导出及特殊字符 XML。
- 游戏名称和选择器 ID 切换、代理商名称查询、重置、无效日期拒绝与日期弹层。
- 开关 403 失败保留状态/勾选，重试成功刷新；移出白名单仅减少列表成员。
- 编辑真实字段保存、金币调整、单/多 APP 行为窗口的会员与游戏范围。
- 排序回首页、分页与 All 的 200 条分批取数、隐藏列、读取失败后重试。
- 延迟写响应不覆盖新的筛选结果，离页后读响应不污染新页面；返回保留筛选和展开状态。
- 1920/1024/390px 视口边界与手机卡片，截图 `visual-baseline/verified/whitelist-mobile.png`。

共享回归通过：金币流水、游戏用户表格、游戏分页、单/多 APP 行为、嵌套会员编辑、会员金币弹窗、提现黑名单。`audit_pages.py` 的 13 个主路由加载通过。测试中没有执行真实支付或参考站业务写入。

## 同数据结果

参考内容视口 1690px；本地屏幕 1920px 减去 230px 侧栏，内容宽度相同。两边注入相同三条记录，包含状态关闭、零金额和特殊字符；均在字体加载后按面板裁图。

| 状态 | 两边尺寸 | 差异像素占比 |
|---|---|---|
| 默认表格 | 1660×320 | 0.0113% |
| 展开筛选 | 1660×416 | 0.0618% |
| 卡片及展开筛选 | 1660×1224 | 0.0216% |

任一 RGB 通道差值超过 16 计为差异，指标不是完成度。14 个默认列宽逐列相同；卡片记录与整面板高度一致。仍有控件边缘和筛选区细节差异，没有宣称逐像素一致。

`compare_whitelist_fixture.py` 比较全量和单条选中两组的 JSON/XML/CSV/TXT/Word/Excel，12 个结果全部内容一致。文本统一 UTF-8 解码；JSON 按结构比较，XML 用标准解析器正规化后比较。默认数据包含 `<>&`，两边 XML 均有效。导出开关保留参考的图标标记，而非自行替换为“是/否”。此结论仅覆盖已捕获的默认列与固定记录。

## 尚未证明

本轮没有完成白名单页面所有隐藏列、头像预览、弹窗每个状态和手机端的双端像素验收。最后登录 IP 的无效链接与本地文本存在上述差异；参考账号的细粒度按钮权限与本地角色映射尚未逐项一致。没有关联游戏的会员行为入口、白名单在风控/抽奖/支付中的实际作用及参考后端收益生成规则仍需核实。

整站目标继续保持未完成，其他页面和真实支付等缺口见 `docs/parity-status.md`。
