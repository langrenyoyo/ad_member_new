## 优先问题

### 1. 广告完成后仍未到账（高）

同日会话 ads_Fy69eSA2OKQs0XC_fFr_rl8m：广告申请、展示、client_complete(pending)、callback_received 均存在。回调 HTTP 602，s_id/e_c/e_c_cny 仍是字面占位符。会话仍 impressed、coin_log_id=null。需要按 TAKU 正式文档配置加密与支持的回调参数，拿到真实 Key ID 和密文，再验证奖励与重复回调幂等；不能跳过核验或手工伪造到账。

### 2. 线上仍为 development 模式（高）

运行进程 APP_ENV=development，JWT 为非默认值。当前 main_from_txt.py 在 production 启动时强制要求可用支付渠道，支付未配置，直接切换会导致启动失败。建议将“服务生产安全模式”和“提现渠道开关”解耦，保持支付未配置时禁止实际出款，再演练生产模式启动、迁移及回滚。本次没有擅自切换。

### 3. 风控尚未形成真实闭环（高）

凭据存在只证明已配置，不证明产品开通、权限或设备 token 可用。应先解决真机触发挑战/校验的问题，在真实 token 调用成功后验证设备关联、标签、限次和解除，再启用规则。旧菜单的固定 503 需迁移到新接口或明确废弃并移除入口。

### 4. 业务规则尚未配置启用（高）

释放/分佣/准入等代码存在但游戏 238 使用关闭或默认值。应根据确认的业务规则配置分段、平台比例、币值转换、奖励上限、四级比例与代理受益人；先试算并验证快照，再启用。不能擅自填入金额/比例来制造“已完成”。

### 5. 两条历史资金流水算术异常（中）

会员 695017，游戏 238：流水 11（2026-10-03）0.09+0.01≠0.099999，差 -0.000001；流水 16（2026-10-05）0.139999+0.01≠0.15，差 +0.000001。两条差异抵消不代表单笔正确。均为历史记录，不能据此认定本轮结算新产生错误。应核对迁移前备份及业务来源，制作可审核的数据修复方案。本次只读，不调整余额或覆盖流水。
