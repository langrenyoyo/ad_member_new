# 禾合用户奖励比例修复

旧模式的 commission_rates[0] 用于普通上级分佣，观看广告的用户获得完整奖励基数，导致后台填写用户50%却发放100%。

新增 commission_basis=shared_base：先按原 ECPM、释放比例、倍率、上限等规则计算分配基数，再给观看者基数乘用户比例；团长、代理分别按同一基数乘各自比例。普通上级不再重复领取用户档。关闭上级分佣不改变用户比例。后台试算与实际结算一致。

禾合配置为用户50%、团长20%、V2 0%、代理每层10%。沿用原有代理逐层规则，不新增总支出封顶。无合格上级的份额不转发给用户。

保留 legacy_additive 默认值兼容旧广告请求快照及其他项目。新模式启用后的广告请求才使用新比例；不追扣已到账金币，不重算旧流水。金币提现兑换比例不变，APK无需更新。

验证涵盖同基数分配、无上级、关闭分佣、ECPM结算与试算一致、旧快照兼容，以及现有会员策略与副广告测试。
