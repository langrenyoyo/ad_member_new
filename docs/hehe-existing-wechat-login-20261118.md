# 已注册微信用户重复登录被要求绑定上级

线上禾合同时开启 require_registration_invite 与 require_invite。微信登录接口本身仅在创建新会员时校验邀请码，但第二项规则会在登录后阻止没有上级的历史会员进入 APP。

调整禾合（game_id=1）策略：require_invite=false，require_registration_invite=true。通过现有后台策略保存函数生效，保留其他参数，保存前备份 settings_json，并记录管理操作日志。不改会员已有上级，不补绑历史用户。

现有 APK 重新启动/刷新账户设置即可读取新策略，无需发布新包。后台以后仅开启“注册必须邀请码”，不要开启登录后强制绑定邀请关系的规则。

回归测试7项通过，新增用例覆盖无上级的既有微信账号登录、退出后再次登录、账户设置不要求上级、新用户缺少邀请码拒绝且不残留会员、新用户提供合格邀请码注册成功。
