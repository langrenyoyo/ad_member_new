# 广告获取失败提示 1.0.20

广告组异常不再将 SDK 异常文本拼接到用户消息。激励、插屏、原生及缺少广告配置的显示入口使用统一配置文案，默认“暂时无法获得广告”。原始广告组异常保留在 Android 诊断日志，现有广告事件上报保持不变。

后台会员规则的“广告来源与公告”新增“无法获取广告时的提示”，按应用保存，最多200字，留空使用默认值。字段 ad_unavailable_message 通过公开规则和登录后规则接口下发；客户端未取得配置时使用默认值。修改文案不要求改动奖励结算配置，也不需要重新打包，客户端下一次获取规则后生效。

Android 1.0.20（21）。验证覆盖文案默认及自定义解析、后端接口下发、后台浏览器保存与重新加载、Android 单元测试和 Lint、正式签名构建。
