## 配置入口

## 已实现业务口径

1. 设备信号：APP 上报 emulator/root/hook/developer/accessibility/bluetooth，后台可选阻断；阿里云仍负责可信设备关联和清机风险。客户端信号可被篡改，不代表完整反作弊保证。蓝牙状态不是连接记录。
2. 清机：启用阿里云限次并打开「清机额度耗尽后限制登录 24 小时」。额度按同一已识别设备共享，最后一次广告申请允许完成，额度耗尽时起算 24 小时；登录、刷新和业务入口执行检查，已有最后一次广告事件允许确认，提现恢复接口可用。自然日限次模式保留作为未启用滚动策略时的旧行为。全新账号/安装首次关联前无法证明它对应哪个云设备；云识别完成前不能宣称能阻断一切清机登录。
3. 释放比例：五类广告平台分别配置 0–1；不是随机克扣广告条数。数字 adsource_id 映射平台；分平台规则要求匹配的 ECPM 证明，不能信任客户端平台名。
4. 奖励：`min(单次上限, ECPM / 1000 × 每元金币 × 平台比例 × 白名单倍率)`，保留 6 位小数。基数选择经过校验的人民币 ECPM 或自定义 ECPM；自定义值是奖励基数，不冒充实际收入。规则在申请广告时快照，在 TAKU 可信回调事务内执行；未启用新策略继续旧结算。
5. 使用统计：系统 Usage Access 设置授权，APP 采集上海时区当日包名、前台时长、估算打开次数；前台定期同步，后台按会员和日期查询。每日同包名覆盖更新，避免重复累加。报告过期或撤权阻止受限业务。系统统计可能包含系统聚合区间偏差，打开次数不是精确使用审计；用户自报授权不能替代设备完整性证明。未申请 QUERY_ALL_PACKAGES。
6. 支付宝：强制引导填写姓名、账户并验证登录密码；微信用户可重新授权设密，短信用户可在引导页验证当前账号手机并确认新密码，无需退出登录。此项不等于支付宝 OAuth 或实名核验。
7. 公告：后台编辑文本及版本，APP 首页展示并定期刷新。
8. 白名单：复用会员 is_white；奖励倍率和风控豁免分开配置，不豁免邀请码、收款信息和使用授权前置。
9. 等级分佣：0 用户 / 1 V1 / 2 V2 / 3 代理。沿邀请链每个等级最近一人获得该等级份额；指定本游戏代理可分该游戏所有符合规则的广告奖励，且不重复拿邀请链代理份额、不自分佣。佣金以最终用户奖励为基数另外支出，不扣用户奖励，四级比例总和不得超过 1。后台和 APP 会员中心可查看流水，奖励/分佣与主奖励同事务并由回调幂等保护。等级默认不自动升级，管理员设置。当前“整个 APP”对应一个游戏 ID，多游戏需分别配置。
10. 登录邀请：微信沿用；短信新增阿里云 SendSms，5 分钟有效、每手机 60 秒间隔/每天 10 次、IP 每天 50 次、错误 5 次锁定、一次使用。邀请码在登录后强制绑定，同游戏且达到后台最低等级才可邀请；禁止自邀、循环和更换上级。

## 外部配置

短信环境变量（仅后端，禁止打包到 APK）：

```
SMS_ALIYUN_ACCESS_KEY_ID=
SMS_ALIYUN_ACCESS_KEY_SECRET=
SMS_ALIYUN_SIGN_NAME=
SMS_ALIYUN_TEMPLATE_CODE=
```

需要开通阿里云短信、审核通过签名和带 code 参数的验证码模板。配置缺失直接返回 503；没有万能码、明文验证码存储或生产模拟发送。

阿里云设备识别、TAKU 回调、ECPM 解密密钥、支付宝服务沿用各自部署文档；不能用设备 SDK AppKey 替代这些服务凭据。

## 修复与验证边界

- 提现待确认申请有独立恢复按钮，不再依赖余额大于零或原档位仍存在；明确未创建错误会清理旧键。
- 广告回调及结算轮询检查发起会话，微信长期订阅不会因旧请求会话取消而永久停止；微信设密等待 120 秒后可重试。
- 关闭 Android 备份，防止登录凭据随应用备份迁移。
- 短信与密码登录独立切换，仅显示一个手机号输入框；短信验证码校验、60 秒重发倒计时、错误提示已补齐。密码和验证码不写入页面恢复状态；退出清理短信挑战，发送响应按会话隔离。
- 冷却期刷新只发受限恢复令牌，可查询余额和恢复原提现；新提现仍被拦截。业务验证码错误不会触发自动刷新并重放请求。
- 需真机验证微信签名/回调、Usage Access 撤权、多机型统计、云设备检测、短信真实发送、各广告平台来源映射与 ECPM、实际支付宝打款。
- 分佣流水已经记账，但广告平台后续收入核减不在现有回调契约内；如需按平台月结对账自动追回，需另外提供核减来源和业务规则，不能伪造回调事件。

此次交付为可配置代码和本地验证，不代表外部服务已开通或已上线。管理端需逐项配置并做真机验收后启用。
